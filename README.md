# SY CROP – Funcionarios

App **instalable** solo para el equipo de trabajo:

- Equipo (funcionarios)
- Producción (foto, prenda, pago completo R$1,40/prenda o por máquina recta/over)
- Vales por persona
- Tarifas editables

Datos en `localStorage` clave `syCropFuncionarios.v1` (independiente de la app de proveedores).

## Deploy
Subí todos los archivos a un repo de GitHub y desplegá en Vercel como sitio estático.
